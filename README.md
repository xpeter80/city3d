# 城市图鉴 · 杭州与成都

依据视频参考重新构建的 Three.js 微缩城市沙盘。布局、色系和操作方式参照原效果，地形及建筑使用程序化几何建模。不是原作者源码或测绘地图，也不声称像素级完全一致。

## 城市选择

左上角「探索城市」切换杭州 / 成都，自动同步三维场景、地标目录、详情、小地图和拍照文件名。记住上次选择；切换时停止旧城市漫游并返回新城市全景。

杭州 15 处地标；成都 13 处地标：天府广场、春熙路与太古里、安顺廊桥、339 天府熊猫塔、宽窄巷子、武侯祠与锦里、环球中心、交子公园与双子塔、熊猫基地、青城山、都江堰、麓湖、锦江绿道。成都为程序化艺术沙盘，地形和区域尺度经过压缩，不是精确 GIS 地图。

## 直接打开

用 Chrome、Edge 或 Safari 双击 `山水杭州.html`。Three.js、OrbitControls、样式、模型与纹理全部内嵌，无需联网、安装依赖、地图密钥或服务器。

## 交互

- 左键拖动旋转，右键拖动平移，滚轮缩放；触屏单指旋转，双指缩放和平移。
- 左侧当前城市地标、地图标记：平滑飞行到目标，打开地标详情。
- 晴昼、日暮、夜游：光照、水色与界面联动；夜晚窗户点亮。
- 全景、环游、自动漫游、涟漪和舟车动画、俯视、地标显隐、拍照、全屏。
- 自动漫游每 9 秒切换地标，手动拖动立即暂停。
- H 返回全景；L 切换地标；空格切换漫游；Esc 返回。
- 拍照导出三维画面 PNG，不包含 HTML 控件。

## 源码

- `chengdu.js`：成都独立场景、地标、小地图与动态舟车。
- `app.js`：场景、程序化地形与模型、材质、镜头和交互。
- `style.css`：桌面及移动端布局。
- `index.html`：模块化开发入口。
- `vendor/`：Three.js 0.160.1 与 OrbitControls。
- `build.py`：使用 esbuild 将源码打包到独立 HTML。

开发预览：在本目录执行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 http://127.0.0.1:8765 。
重新打包：安装 esbuild 后执行 `python3 build.py`。

## 环球中心模型更新

按用户提供的建筑参考图重建四角上扬的银色屋顶环、中央椭圆玻璃穹顶与骨架、下凹庭院、横向玻璃幕墙和层叠弧形入口；入口前留出广场，避免程序化楼群遮挡。

## 双子塔模型更新

依据用户提供的两张日间与傍晚照片重建椭圆塔身、镜像竖向曲线带、斜切冠顶、细密三角幕墙和低矮椭圆裙房。夜景启用轮廓灯与暖色窗光。仍为艺术化微缩模型。

## 麓湖模型更新

按用户提供的三张参考照片重做半岛水巷、折面别墅、临水露台、小码头与错层露台住宅，增加密集岸边绿化并同步小地图。

## 手机布局与发布记录

宽度小于 768px 自动切换手机布局，矮横屏使用紧凑布局。顶部保留城市选择和音乐开关，「探索」菜单集中景点、手记、我的与其他工具。景点详情支持摘要、半屏和展开，留言文字草稿可恢复。
